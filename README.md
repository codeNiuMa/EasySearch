# EasySearch

EasySearch 是一个低干扰的搜索起点。它不聚合内容，也不加载推荐信息流；用户选择搜索入口、输入关键词后，会直接打开目标网站的搜索结果页。

## 当前版本

项目已从早期的 Python/CustomTkinter 练习程序改造为纯静态网页：

- 不需要后端、数据库或构建工具；
- 页面本身不请求第三方字体、图标或内容资源；
- 支持桌面和移动端；
- 记住主题与最后使用的搜索入口；
- 支持在浏览器中添加自定义搜索入口，数据仅保存在本机；
- 支持键盘快捷操作。

网页源码位于 `dist/`，可以直接部署到任意静态托管服务。

## 本地预览

使用任意静态文件服务器打开 `dist/` 即可。直接双击 `dist/index.html` 也可以使用主要功能。

## 自定义入口格式

搜索地址必须包含 `{query}` 占位符，例如：

```text
https://developer.mozilla.org/zh-CN/search?q={query}
```

提交搜索时，EasySearch 会把 `{query}` 替换为经过安全编码的关键词。

## 旧版

仓库根目录中的 Python 文件保留作为项目早期版本的记录。新的网页版本不依赖它们。
